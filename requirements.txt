# homebrew 的 python 被标成 externally-managed（PEP 668），上面这条会被拒，
# 回答是 `error: externally-managed-environment`。这台机器上两个包都装在
# user site（~/Library/Python/<ver>/lib/python/site-packages），加一个 flag：
#
#     python3 -m pip install --user --break-system-packages -r requirements.txt
#
# `--user` 不能省 —— homebrew 自己的提示也这么说。有它，写入只落在 user site，
# 不碰 homebrew 自己那份。venv 在这里解决不了问题：selfcheck 和所有脚本调的是
# 裸 `python3`，不会进 venv，装在 venv 里等于没装。
#
# 为什么需要这份声明：2026-11-01 homebrew 把 `python3` 切到 python@3.15，而这些
# 包一直装在系统 3.9 上。于是 safeyaml.py 对每一处 yaml 锁报 BLOCKED，selfcheck
# 在第 425 行退出，11 条锁以看起来互不相干的方式失败，negative 锁还因为「期望非 0
# 退出」而把 BLOCKED 当成通过。依赖隐式存在时，换解释器就是这个后果。
#
# 跑 `bash scripts/selfcheck.sh`，它的 preflight 会先说清缺什么、用的哪个解释器。
