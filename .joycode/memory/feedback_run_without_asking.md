description: 用户要求任务执行中不要反复征求许可，直接运行命令、接受变更、自动重试；禁止使用提问类工具

任务执行期间（研究、验证、跑测试、执行命令、文件变更）不要向用户询问确认，直接执行。**禁止使用 task_ask_question 之类的提问工具**，哪怕它声明"仅在必要时使用"。

**Why:** 用户 2026-11-01 首次反馈"不要一直问我"；2026-11-04 再次连发两次"工作期间不要一直询问我，遇到'运行命令'直接同意通过即可"并质问"为什么还在问我"。此前在运行命令前反复请求确认，拖慢协作，用户已明显不耐烦。

**How to apply:** 只读/验证类命令（git、ls、cat、测试脚本、构建）直接执行；文件编辑按计划直接进行并接受变更；命令失败直接重试；后台任务（nohup 等）直接启动。不弹任何问题、不请求任何确认。仅当操作真正不可逆且触及用户资产安全（如永久删除、强推远端）时，依赖工具自身的安全机制（回收站/审批），而非先问用户。若 IDE 层仍弹命令审批窗口，那是用户侧 IDE 设置，不在回复中反复解释，一句话带过即可。
