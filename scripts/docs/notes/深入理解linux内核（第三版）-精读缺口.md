## 一、精读范围

全书 20 章读完（约 34.6K 行 OCR），主区间如下：

- 第 1–2 章「绪论 / 内存寻址」（L161–L191）：内核概览、分段与分页、线性地址。
- 第 3–6 章「进程 / 中断和异常 / 内核同步 / 定时测量」（L192–L249）：进程描述符、中断处理、自旋锁 / 信号量 / RCU、时钟与定时器。
- 第 7–9 章「进程调度 / 内存管理 / 进程地址空间」（L250–L293）：调度算法、页框管理、地址空间。
- 第 10–11 章「系统调用 / 信号」（L294–L305）：系统调用入口、信号处理。
- 第 12–14 章「虚拟文件系统 / I/O 体系结构和设备驱动程序 / 块设备驱动程序」（L306–L347）：VFS、设备驱动、块设备。
- 第 15–18 章「页高速缓存 / 访问文件 / 回收页框 / Ext2 和 Ext3 文件系统」（L348–L370）：页缓存、文件访问、页回收、文件系统。
- 第 19–20 章「进程通信 / 程序的执行」（L371–L405）：管道、信号量、消息队列、exec。

重点复核段落：内核同步与锁（第 5 章）；进程调度（第 7 章）；内存管理与页框回收（第 8、17 章）；页高速缓存（第 15 章）；虚拟文件系统（第 12 章）。
