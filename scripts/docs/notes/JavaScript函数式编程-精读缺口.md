## 一、精读范围

## 三、真缺口

**零缺口。** 本书可推广的工程原则（纯函数与命令/查询分离、不变性与消除共享可变状态、提取纯函数可单测、函数组合闭合、递归收敛、循环闭包捕获、隐藏实现、组合优于继承）已由 T3/T4/T10/T14、C20/C21/C24/C26/C27/C33/C34、P6/P19、F5 承载；其余为函数式语言机制与工具库教程，不落真源。

## 四、重点候选裁定（防后人重复发现）

1. **「函数式编程范式」不另立为独立条目。** 其可执行落点（纯函数、不变性、组合、收敛）已由 C21/T14/P19/C20/C33 分别承载；把整个范式立成通用规则会与多语言仓的既有条目重复，且与命令式代码共存时难界定边界。
2. **柯里化 / 偏应用不另立。** 属函数式语言技巧；其“把多参函数拆成可复用单参函数”的复用价值由 T7（DRY 第 3 次才抽）与 P19（闭合操作）承载，不把具体柯里化写法固化成规则。
3. **蹦床（trampoline）/ 尾调用优化不另立。** 属 JavaScript 递归局限的绕过技巧；其“递归收敛要有显式进度度量”的要求已由 C20/C33 承载。
4. **惰性链 / 惰性求值不另立。** 属函数式库实现细节；其“先正确清晰、再度量再优化”的纪律由 T9 承载，不预设惰性求值。
5. **Mixins 具体实现不另立。** “组合优于继承”已由 C27 承载；具体 Mixin 拼装是语言技巧，非工程缺口。
6. **函数式库选型（Underscore.js / RxJS / Bilby / allong.es）不另立。** 属工具选择；其“不猜第三方 API、先读源码”由 F2 承载。
