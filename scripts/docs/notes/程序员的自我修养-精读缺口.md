## 一、精读范围

## 四、重点候选裁定（防后人重复发现）

1. **接口 / 实现分离、系统调用分层不另立。** T3（信息隐藏）/ T4（依赖边界）已承载。
2. **DLL Hell / ABI 兼容性不另立。** T13 已承载（语义变了就换名 / 升版本号，旧名保留原语义直到下线）；「接口不向后兼容就升主版本号」是 T13「升版本号」在共享库的具体表现。
3. **SO-NAME / 版本命名不另立。** T13 已承载（升版本号让不兼容在编译 / 启动期暴露）。
4. **符号修饰 / 名称修饰不另立。** C18（跨进程交换不依赖内存布局、字节序与版本写进格式）已承载，且名称修饰是 C++ ABI 的语言实现事实。
5. **强符号 / 弱符号 / 符号重复定义不另立。** 链接器符号决议规则是系统事实；「弱符号可被用户强符号覆盖」是 C 语言扩展点机制，属语言课内容。
6. **可重入 / 线程安全不另立。** T14（可变性默认纯值）已承载；可重入函数「仅依赖参数、不碰静态 / 全局变量」是 T14 纯值边界的 C 语言表述。
7. **锁 / 临界区 / 读写锁不另立。** T10（共享可变数据与锁绑定封装、临界区最小化、锁排序）已承载。
8. **过度优化破坏线程安全不另立。** T10 已承载（并发准入）；编译器 / CPU 指令重排序、volatile / memory barrier 是内存模型系统事实，不进真源。
9. **静态 vs 动态链接的权衡不另立。** 部署 / 升级策略（空间节省、升级灵活性 vs 性能损失）是部署决策，非代码气味，不进 T/C/P/R。
10. **堆分配算法（空闲链表 / 位图 / 对象池）不另立。** 算法课内容，不进真源。
