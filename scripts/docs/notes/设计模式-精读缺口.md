## 三、真缺口

### 缺口 1｜继承纪律（组合优于继承 + LSP 覆写纪律 + 层级上限）→ coding-tables.md §2 新增 C27

- **出处**：禅 LSP 章——定义二（子类必须能替换父类）L1364-1366；ToyGun 继承惨案、依赖/聚集/组合代替继承 L1505-1531；向下转型不安全 L1532-1602；契约设计异曲同工 L1604-1608；覆写时前置条件只能更宽松 L1666-1668、L1732-1733；返回只能更窄 L1734-1744；尽量避免子类个性 L1749-1752；DIP 章最佳实践——继承层级不超过两层 L2060-2066、尽量不覆写基类已实现方法 L2067-2069。HeadFirst 第1-4章——继承接口/实现反例 L1828-1838、L1875-1877；继承被绑死 L1953-1956；「有了继承的复用好处，却没有继承的包袱」L2088-2090；Duck 不必上接口 L2104-2110；第9-10章组合定义 L16802-16804、多用组合少用继承 L18772、委托而非继承 L19923-19959；第10章状态类委托行为 L19025-19057；模式痛 L2660-2662。
- **论据**：真源对继承只有「场景选型」没有「纪律检查」。P4 管「追加行为时选 SPI 不叠基类」，是 diff 前的选型视角；一旦合法场景用了继承（P12 模板方法、真抽象基类），没有一条规则管这个继承结构本身是否健康。两书反复给出的检查点真源全缺：①继承只为复用代码而非 is-a 行为多态→ToyGun 惨案（运行期才爆）；②覆写丢/弱化基类已实现行为→禅最佳实践第4条；③覆写前置条件收窄、返回放大→LSP 定义二的量化表述；④层级超两层→DIP 最佳实践「两层的继承还可以忍受」；⑤HeadFirst 整个第1章就是把继承复用改造成组合复用的活案例（行为放独立对象，运行期换）。
- **建议落点**：coding-tables.md §2 C25 后新增 C27（与可读性缺口 C26 连续编号）。
- **与最相近条目的区别**：P4「不要：为复用垂直叠基类」是场景行，管「追加通过后怎么做」的选型时机；C27 是气味行，review 扫已存在的继承结构：is-a 是否成立、覆写是否守约、层级是否超限。C22 管调用方挖协作者内部（迪米特），与继承结构正交。
- **落地状态（已提交）**：本缺口已在 commit `bef5291`（feat: land self-evolution and book distillation updates）落地——`conventions/coding-tables.md` §2 新增 C27「继承只为复用代码而非 is-a 行为多态；层级超两层；子类覆写丢弃 / 弱化基类已实现行为，或覆写收窄前置条件、放大返回」，纠正「复用走组合 / 依赖 / 聚集；is-a 成立才继承且子类必须能完整实现父类行为；覆写守约：前置条件只能更宽松、返回只能更窄；层级 ≤2」。`deep-read-audit.py` 与 `trigger-check.py` 均 PASS。
