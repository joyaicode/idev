## 一、精读范围

全书 19 章读完（约 48.2K 行 OCR），主区间如下：

- 第 1–2 章「UNIX 基础知识 / UNIX 标准及实现」（L339–L1365）：登录、文件与目录、输入输出、程序与进程、出错处理、标准与实现差异。
- 第 3–6 章「文件 I/O / 文件和目录 / 标准 I/O 库 / 系统数据文件」（L1366–L…）：不带缓存 I/O、文件属性、标准 I/O 缓冲、口令与系统数据。
- 第 7–10 章「进程环境 / 进程控制 / 进程关系 / 信号」（L…–L…）：进程生命周期、fork/exec、进程组与会话、信号处理。
- 第 11–13 章「线程 / 线程控制 / 守护进程」（L…–L…）：线程同步、互斥与条件变量、守护进程。
- 第 14–15 章「高级 I/O / 进程间通信」（L…–L…）：非阻塞 I/O、记录锁、管道、消息队列、共享内存。
- 第 16–19 章「网络 IPC：套接字 / 高级进程间通信 / 终端 I/O / 伪终端」（L…–L…）：套接字、终端与伪终端。

重点复核段落：出错处理与资源释放（第 1、3 章）；信号与竞态（第 10 章）；线程同步与锁（第 11、12 章）；进程间通信与套接字（第 14–16 章）。

## 四、重点候选裁定（防后人重复发现）

1. **「资源成对释放」不另立。** C19 已要求同层成对、释放显式、覆盖所有路径，不单列。
2. **「出错处理 / errno 传播」不另立。** 已由 T8（快速失败）与 C38（库函数失败向上传播）承载。
3. **「线程同步与锁」不另立。** 已由 T10（并发控制 / 锁排序）与 C39（锁按值复制）承载。
4. **「字节序与跨进程格式」不另立。** C18 已管显式交换格式与字节序。
5. **「缓冲策略（标准 I/O vs 不带缓存）」不另立。** 是 T9「先度量再优化」的实例。
