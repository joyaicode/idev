## 四、重点候选裁定（防后人重复发现）

1. **内存池 / 所有权移交不另立。** 「分配与释放分离、释放交池负责」是 C 语言无 GC 场景的特定解法；其要解决的泄漏/双重释放已由 C19（同层成对、显式释放、覆盖所有路径）承载。把内存池当通用规则会与 C19 重复。
2. **事件驱动 / 非阻塞 I/O 不另立。** 高并发与异步的纪律已由 T10（数据系统是权衡）与 T11（可运维性：超时/连接池/熔断）承载；epoll/kqueue 是平台 API。
3. **upstream 背压（有界缓冲 + 落盘）不另立。** 「慢响应是最坏的故障模式、无界等待拖垮调用链」已由 T11 承载；缓冲大小与落盘阈值是 Nginx 配置细节。
4. **缓冲区 shadow 引用复用不另立。** 属 Nginx 实现技巧；「释放显式、别名防篡改」已由 C19/T14 承载。
5. **进程间通信（共享内存/锁/信号）不另立。** 并发与共享状态的准入已由 T10/T11/T14 承载；具体 IPC 机制是平台能力。
6. **平滑升级（HUP/USR2）不另立。** 不停服变更已由 T11（灰度/回滚/降级）与 A6（回滚路径）承载。
