## 一、精读范围

全书 11 章读完，OCR 主区间如下：

- 第 1 章「了解 Web 及网络基础」（L758–L1318，PDF 20–36）：TCP/IP 协议族、IP/TCP/DNS、URI/URL。
- 第 2 章「简单的 HTTP 协议」（L1319–L1932，PDF 36–55）：客户端/服务器通信、无状态、HTTP 方法、持久连接、管线化、Cookie 状态管理。
- 第 3 章「HTTP 报文内的 HTTP 信息」（L1933–L2247，PDF 55–65）：报文结构、内容编码、分块传输、范围请求、内容协商。
- 第 4 章「返回结果的 HTTP 状态码」（L2248–L2517，PDF 65–74）：2XX 成功、3XX 重定向、4XX 客户端错误、5XX 服务器错误。
- 第 5 章「与 HTTP 协作的 Web 服务器」（L2518–L2764，PDF 74–83）：虚拟主机、代理/网关/隧道、缓存。
- 第 6 章「HTTP 首部」（L2765–L4566，PDF 83–128）：通用/请求/响应/实体首部字段、Cookie 首部。
- 第 7 章「确保 Web 安全的 HTTPS」（L4567–L5379，PDF 128–149）：SSL/TLS、加密机制、证书认证。
- 第 8 章「确认访问用户身份的认证」（L5380–L5758，PDF 149–160）：Basic/Digest/SSL 客户端认证。
- 第 9 章「基于 HTTP 的功能追加协议」（L5759–L6242，PDF 160–173）：SPDY、WebSocket、WebDAV。
- 第 10 章「构建 Web 内容的技术」（L6243–L6566，PDF 173–183）：HTML/CSS、动态 HTML、Web 应用。
- 第 11 章「Web 的攻击技术」（L6567–L7915，PDF 183–265）：跨站脚本、SQL 注入、跨站请求伪造等。

重点复核段落：无状态与 Cookie L1319–L1932（PDF 36–55）；状态码语义 L2248–L2517（PDF 65–74）；代理/网关/隧道与缓存 L2518–L2764（PDF 74–83）；HTTPS 与证书 L4567–L5379（PDF 128–149）；Web 攻击 L6567–L7915（PDF 183–265）。

## 三、真缺口

**零缺口。** 本书可推广的工程原则（无状态与状态外置、缓存与派生数据一致性、代理/网关/隧道、状态码快速失败、连接池与持久连接、密钥与加密管理、身份认证、Web 攻击防护）已由 T8/T9/T10/T11/T14、A4、P9/P10、C2/C31 承载；其余为 HTTP 协议与 Web 技术参考，不落真源。

## 四、重点候选裁定（防后人重复发现）

1. **HTTP 状态码语义不另立为独立条目。** 其“结果语义明确、未列值报错”的可执行要求已由 T8/C2 承载；具体状态码（200/301/302/400/401/403/404/500/503）是协议事实，不抄进产品仓。
2. **缓存机制（Cache-Control/ETag/缓存有效期限）不另立。** 缓存是派生数据的一种，其一致性由 A4（派生/副本、一致性等级）与 T9/T10 承载；具体 HTTP 缓存头是协议细节。
3. **代理/网关/隧道不另立。** P10（Proxy）与 T11（可运维性）已承载转发与连接管理；具体协议转换是选型。
4. **HTTPS/SSL/证书/加密不另立。** C31 已承载密钥管理与“只用公认加密实现”；具体 TLS 握手与证书链是协议参考。
5. **身份认证方案（Basic/Digest/SSL 客户端）不另立。** P9（Chain）与 C31（每服务自己的凭证）已承载；具体认证协议是选型。
6. **Web 攻击清单（XSS/SQL 注入/CSRF 等）不另立。** C31 与 security-and-hardening 技能已承载安全基线；具体攻击向量是安全审计参考。

## 五、不建议落的内容

- 状态码一览表（200/204/206/301/302/303/304/307/400/401/403/404/500/503）：协议事实，不抄进产品仓。
- 首部字段一览（通用/请求/响应/实体/Cookie 首部）：协议参考。
- SSL/TLS 握手、证书链、SPDY/WebSocket/WebDAV/HTTP2 协议细节：协议参考。
- Web 攻击向量（跨站脚本、SQL 注入、跨站请求伪造、会话劫持等）的具体手法：安全审计参考。
