## 四、重点候选裁定（防后人重复发现）

1. **「事务语义（请求/应答）」不另立。** T10 / A4 已承载失败语义与一致性等级；「事务」在本书指请求/应答而非数据库事务，不进通用规范。
2. **「超时 / 幂等 / 连接池」不另立。** `canon.md` §2/§4 已承载超时、重试幂等、keep-alive 连接池信号。
3. **「无状态 HTTP」不另立。** A4 一致性等级与 §2 连接复用信号已承载。
4. **「UNIX 域套接字 / 本地 IPC」不另立。** C18 已承载「跨进程交换数据不依赖内存布局」。
5. **「T/TCP 加速打开」不另立。** 协议优化细节，不进通用规范。
