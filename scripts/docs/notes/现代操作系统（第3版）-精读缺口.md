## 一、精读范围

全书 12 章读完，OCR 主区间如下（行号指 `现代操作系统（第3版）-OCR.txt`）：

- **第 1 章 引论**：操作系统抽象（CPU→进程、物理内存→地址空间、磁盘→文件）、系统调用、接口设计。
- **第 2 章 进程与线程**：进程模型、线程、进程间通信、临界区、忙等待互斥、信号量、管程、调度。

- **第 4 章 文件系统**：文件抽象、目录、实现、一致性。
- **第 5–6 章 输入/输出 / 死锁**：I/O 原理、死锁的检测与避免。

1. **「抽象（进程 / 地址空间 / 文件）」不另立。** T3/T4 已承载深模块与依赖边界；OS 三大抽象是系统课内容。

3. **「资源配平」不另立。** C19/C39 已承载资源获取释放成对与持有资源的类型语义。
4. **「性能权衡（调度 / 置换 / 缓存）」不另立。** T9/T10 已承载「先正确再优化、权衡」。
5. **「安全（权限 / 隔离）」不另立。** C31 与 `security-and-hardening` 技能已承载。
6. **「一致性（崩溃一致性 / 写时复制）」不另立。** A4 已承载一致性等级与派生 / 副本。
