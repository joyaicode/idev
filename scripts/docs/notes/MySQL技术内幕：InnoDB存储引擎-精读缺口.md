## 一、精读范围

全书 10 章读完（约 19.5K 行 OCR），主区间如下：

- 第 1 章「MySQL 体系结构和存储引擎」（L701–L1317）：插件式存储引擎、各引擎比较、连接方式。
- 第 2 章「InnoDB 体系架构」（L1318–L2460）：后台线程、内存（缓冲池 / 重做日志缓冲）、master thread、插入缓冲、两次写、自适应哈希索引、启动关闭与恢复。
- 第 3 章「文件」（L2461–L3567）：参数文件、日志文件（错误 / 慢查询 / 查询 / 二进制）、表空间、重做日志。
- 第 4 章「表」（L3568–L9232）：逻辑 / 物理存储结构、行记录格式、数据页结构、约束。
- 第 5 章「索引与算法」（L9233–L11308）：B+ 树索引、哈希索引、二分查找、全文检索。
- 第 6 章「锁」（L11309–L12300）：共享 / 排他锁、一致性非锁定读（MVCC）、锁算法、死锁、阻塞。
- 第 7 章「事务」（L12301–L13421）：ACID、redo/undo、预写日志（WAL）、隔离级别、分布式事务。
- 第 8 章「备份与恢复」（L13422–L15052）：热备 / 冷备 / 温备、逻辑 / 裸文件、完全 / 增量 / 日志备份、一致性。
- 第 9 章「性能调优」（L15053–L16304）：CPU / 内存 / 磁盘 / RAID / 文件系统 / 基准测试。
- 第 10 章「InnoDB 存储引擎源代码的编译」（L16305–L16801+）：源码结构、编译调试。

重点复核段落：锁与 MVCC（第 6 章）；事务与 WAL（第 7 章）；备份一致性（第 8 章）；性能调优与基准测试（第 9 章）。
