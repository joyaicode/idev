## 一、精读范围

全书 27 章 + 附录读完（约 50.6K 行 OCR），主区间如下：

- 第 1–2 章「简介 / 传输层：TCP 和 UDP」（L150–L236）：客户—服务器模型、包裹函数、TCP/UDP 语义。

## 四、重点候选裁定（防后人重复发现）

1. **「套接字资源成对释放」不另立。** C19 已要求同层成对、释放显式，不单列。
2. **「包裹函数统一出错处理」不另立。** 已由 T8（快速失败）与 C38（库函数失败向上传播）承载。
3. **「线程化服务器与并发」不另立。** 已由 T10（并发控制 / 锁排序）与 C39（锁按值复制）承载。
4. **「网络字节序」不另立。** C18 已管显式交换格式与字节序。
5. **「I/O 复用 vs 多线程的选择」不另立。** 是 T9「先度量再优化」的实例。
6. **「协议无关编程」不另立。** 已由 C16（共同支持子集）与 C17（环境差异收拢）承载。
