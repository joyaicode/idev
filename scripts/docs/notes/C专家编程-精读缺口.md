> 源文本：`scripts/docs/notes/C专家编程-OCR.txt`（Peter van der Linden《Expert C Programming: Deep C Secrets》中文版，人民邮电出版社；307 页扫描版无文本层，经 macOS Vision OCR 逐页识别）。本报告为第 24 本精读，对照 `conventions/canon.md`、`conventions/coding-tables.md`、`deliver/references/experts.md` 裁定真缺口。
>
> 边界：编号真源仍只认 `canon.md` 的 T/A/F 与 `coding-tables.md` 的 P/C/R；本书是 C 语言教程，绝大多数章节是语言 / 工具链 / 硬件事实（数组≠指针、声明分析、链接、运行时数据结构、内存模型、类型转换、原型、多维数组、指针），只作溯源，不建第二套编号。语言特性（语法课）归学习向 Skill，不落多语言仓，见 §五。

## 一、精读范围

全书 11 章 + 附录 A/B 读完，OCR 主区间如下（行号指 `C专家编程-OCR.txt`，PDF 页号随注）：

- **第 1 章 C：穿越时空的迷雾**（L397–L1284）：C 语言史前阶段、早期体验、标准 I/O 库与预处理器、K&R C、ANSI C、编译限制、「安静的改变」。
- **第 2 章 这不是 Bug，而是语言特性**（L1338–L2322）：多做之过 / 误做之过 / 少做之过、有些特性确实就是 Bug。
- **第 3 章 分析 C 语言的声明**（L2339–L3477）：声明语法、优先级规则、图表分析、typedef、声明与使用相似的设计哲学。
- **第 4 章 令人震惊的事实：数组和指针并不相同**（L3533–L3831）：数组并非指针、声明 vs 定义、数组与指针的其他区别。
- **第 5 章 对链接的思考**（L3867–L4840）：函数库 / 链接 / 载入、动态链接优点、库链接的 5 个秘密、Interpositioning、链接器报告文件。
- **第 6 章 运动的诗章：运行时数据结构**（L4841–L5688）：a.out 与段、操作系统 / 运行时系统在 a.out 里干了什么、过程活动记录、auto/static、setjmp/longjmp、UNIX 堆栈段。
- **第 7 章 对内存的思考**（L5740–L6833）：Intel 80x86 内存模型、虚拟内存、Cache、数据段与堆、内存泄漏、总线错误。
- **第 8 章 为什么程序员无法分清万圣节和圣诞节**（L6882–L8003）：位模式、类型转换、原型之痛、有限状态机、软件比硬件更困难、强制类型转换。
- **第 9 章 再论数组**（L8058–L8714）：什么时候数组与指针相同、数组片段下标、多维数组、软件/硬件平衡。
- **第 10 章 再论指针**（L8764–L9464）：多维数组内存布局、Iliffe 向量、锯齿状数组、向函数传递数组、动态数组、程序检验的限制。
- **第 11 章 你懂得 C，所以 C++ 不在话下**（L9526–L10522）：OOP 四特征（抽象/封装/继承/多态）、访问控制、重载、多重继承、C++ 简单子集、软件复用。
- **附录 A 程序员工作面试的秘密**、**附录 B 术语表**。

重点复核段落：第 8 章「用 C 语言实现有限状态机」（L7391–L7446）、「软件比硬件更困难」（L7449–L7515）；第 10 章「程序检验的限制」（L9351–L9409）；第 11 章「C++ 的一个简单子集」（L10281–L10366）。

2. **链接 / 运行时数据结构 / 内存模型（第 5/6/7 章）不落。** 工具链 / 硬件事实。
3. **类型转换 / 原型 / 位模式（第 8 章）不落。** C 语言事实。
4. **有限状态机不另立。** P5（按类型选算法 / 一处 switch）已承载；本书 FSM 实现（函数指针数组）是 C 特有形，不落。
5. **可调试性 / debugging hooks 不另立。** T11（可运维性/观测）已承载；debugging hooks 是调试器特性，不落。
6. **程序检验的限制不另立。** 与《编程珠玑》第 4 章同源，增量已落 C33。
7. **C++ 简单子集 / 复用不另立。** T1（先砍偶然复杂度）/ T7（DRY）已承载。
8. **OOP 四特征不另立。** T1/T3/T4/C27 已承载；再加会变成口号。
