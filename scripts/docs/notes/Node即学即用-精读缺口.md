## 四、重点候选裁定（防后人重复发现）

1. **事件循环 / 事件驱动 / 非阻塞 I/O 不另立。** T10/T11 已承载（队列/异步/事件、可运维性）；事件循环是其在 Node 的具体实现。
2. **单线程并发取舍不另立。** T14（可变性默认纯值）与 T10（并发准入：先单线程版本测试通过再引入线程）已承载。
3. **回调地狱不另立。** C9/C1/T3 已承载（卫语句、拆职责、深模块）；声明式函数拆分与中间件是其解法。
4. **异步差错处理（try/catch 对回调无效）不另立。** T8/C7/C38 已承载「异步错误必须显式传递、不得静默吞」；error 事件与 error-first 回调是其在 Node 的具体约定。
5. **多处理器 / cluster / 僵尸进程监控不另立。** T11（可运维性：指标、重启、降级）与 T10（状态共享）已承载；cluster 是其运行时实现。
6. **连接池不另立。** T11「连接池上限与复用、外部调用超时」已承载；generic-pool 的 max/idleTimeoutMillis 是其具体实现。
7. **消息队列协议（工作队列 / 发布-订阅 / ack / 死信）不另立。** T10「消费拓扑（点对点/发布-订购）、重试幂等、死信、无界重试禁止」已承载；AMQP/RabbitMQ 是其具体实现。
8. **加密不另立。** C31（安全）已承载。
9. **assert 测试不另立。** T6（护栏先行）与 F5（自证式测试）已承载。
10. **中间件单一职责与状态传递不另立。** T3（深模块）、C1（拆职责）、T14（状态显式传递）已承载。
