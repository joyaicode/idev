> 边界：编号真源仍只认 `canon.md` 的 T/A/F 与 `coding-tables.md` 的 P/C/R；本书「第 N 章」序号只作溯源，不建第二套编号。UNIX 内核实现细节（缓冲区、inode、调度、内存管理、设备驱动、IPC、多处理器、分布式文件系统）、C 语言、System V/BSD 具体 API 与机器相关指令是操作系统/技术栈参考，不进产品仓真源；只提炼跨语言工程原则。

## 一、精读范围

全书 13 章 + 前言 + 附录（系统调用）+ 参考文献 + 索引读完（约 100 万字符，484 页文本层），主区间如下：

- 第 1 章「系统总览」（L421–L1070）：用户态/内核态、系统调用、小程序组合哲学（管道 + I/O 重定向）、硬件假设（中断/异常、处理器执行级）。
- 第 2 章「内核导论」（L1097–L1783）：文件子系统 + 进程控制子系统两层架构、inode/超级块、进程状态机、非抢占内核、sleep/wakeup、临界区关中断。
- 第 3 章「缓冲区高速缓存」（L1790–L2600）：缓冲区头、缓冲区池、LRU 替换、哈希队列、锁与 delayed-write、getblk/bread/bwrite。
- 第 4 章「文件的内部表示」（L2605–L3754）：inode、目录、路径名→inode、超级块、磁盘块分配、竞态条件。
- 第 5 章「文件系统系统调用」（L3760–L5890）：open/read/write/lseek/close、文件与记录锁、管道、dup、挂载/卸载、link/unlink、文件系统抽象、fsck。
- 第 6 章「进程结构」（L5895–L7873）：进程状态与迁移、进程上下文（用户级/系统级）、区域、页表、sleep/wakeup。
- 第 7 章「进程控制」（L7878–L10022）：fork/exec/exit/wait、信号、setuid、brk、shell 与 init。
- 第 8 章「进程调度与时间」（L10027–L11219）：调度优先级、CPU 衰减、nice、时钟中断、callout 表。
- 第 9 章「内存管理策略」（L11224–L12883）：换出 vs 按需分页、copy-on-write、驻留要求防抖动、页偷取/有效性故障。
- 第 10 章「I/O 子系统」（L12888–L14604）：驱动接口、磁盘/终端驱动、streams 模块化。
- 第 11 章「进程间通信」（L14609–L16103）：ptrace、System V 消息/信号量/共享内存、套接字、`IPC_NOWAIT`/条件 P 防死锁。
- 第 12 章「多处理器系统」（L16108–L17680）：主从 vs 信号量、sleep-lock 竞态、原子 test-and-set、Dijkstra P/V/CP、非线性扩展。
- 第 13 章「分布式 UNIX 系统」（L17685–L20171）：卫星处理器、Newcastle 连接、透明分布式文件系统、RPC vs 远程系统调用、stub vs 服务器池。

重点复核段落：非抢占内核与 sleep/wakeup（第 2、6 章）；缓冲区/inode 竞态与锁（第 3、4 章）；调度优先级与 CPU 衰减（第 8 章）；换出/按需分页与防抖动（第 9 章）；IPC 与死锁避免（第 11 章）；多处理器主从 vs 信号量（第 12 章）；分布式文件系统（第 13 章）。

## 四、重点候选裁定（防后人重复发现）

1. **「简单一致哲学 / 小程序组合」不另立。** 已由 T1（先砍偶然复杂度）与 T3（深模块）承载，是 UNIX 哲学的实例。
2. **「非抢占内核 + sleep/wakeup + 关中断临界区」不另立。** 是并发控制的特定实现，已由 T10（并发/锁/共享可变状态）承载。
3. **「缓冲区/inode 竞态与锁」不另立。** 已由 T10（锁排序）与 C39（锁按引用/身份）承载。
4. **「LRU 缓存 / delayed-write / copy-on-write」不另立。** 是 T10（数据系统是权衡：cache/派生副本）与 A4（数据真相之源、副本）的实例。
5. **「进程状态机」不另立。** 已由 T14（可变性默认纯值）与状态逻辑承载。
6. **「调度优先级 + CPU 衰减」不另立。** 是 T9「先度量再优化」的实例。
7. **「换出 vs 按需分页 + 驻留要求防抖动」不另立。** 已由 T9/T10 承载。
8. **「IPC_NOWAIT / 条件 P 防死锁」不另立。** 已由 T10（并发/死锁）承载。
9. **「主从 vs 信号量、非线性扩展」不另立。** 已由 T10（并发）与 T12（架构 = 有记录的权衡）承载。
10. **「分布式文件系统 / RPC vs 远程系统调用 / stub vs 服务器池」不另立。** 已由 A4（数据真相之源、失败语义、一致性等级）与 T10 承载。
