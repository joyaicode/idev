## 一、精读范围

全书 14 章 + 3 附录读完，文本主区间如下（行号指 `Node.js实战-全文.txt`，PDF 页号随注）：

- 第 1 章 欢迎进入 Node.js 世界：事件驱动、非阻塞 I/O、DIRT（数据密集型实时）程序、流数据与管道（L572–L925）。
- 第 2 章 构建有多个房间的聊天室程序：HTTP + WebSocket、依赖项（package.json）、静态文件服务器（L926–L1591）。
- 第 3 章 Node 编程基础：模块系统（module.exports / node_modules）、回调与事件发射器（Pub/Sub）、错误事件、异步串行/并行流程控制（L1592–L2481）。
- 第 4 章 构建 Node Web 程序：HTTP 服务器、RESTful 服务、静态文件服务、先发制人错误处理（fs.stat）、HTTPS（L2482–L3179）。
- 第 5 章 存储 Node 程序中的数据：内存/文件/关系型/NoSQL 存储、数据存储五因素、基于文件存储的并发问题（L3180–L3897）。
- 第 6 章 Connect：中间件工作机制、中间件顺序（认证在静态文件前）、挂载、可配置中间件（闭包）、错误处理中间件（L3898–L4619）。
- 第 7 章 Connect 自带的中间件：cookie/签名 cookie、bodyParser、limit（防 DoS）、basicAuth、csrf、errorHandler、static（恶意路径检查）（L4620–L5519）。
- 第 8–9 章 Express 与 Express 进阶：路由、视图、认证、内容协商、404 与错误处理（L5520–L7219）。
- 第 10 章 测试 Node 程序：单元测试（assert/Nodeunit/Mocha/Vows/should.js）、验收测试（Tobi/Soda）、TDD/BDD、异步测试隔离（L7220–L7876）。
- 第 11 章 Web 程序模板：MVC 分层、EJS/Hogan/Jade 模板、XSS 转义、模板继承与组织（L7877–L8656）。
- 第 12 章 部署 Node 程序并维持正常运行时间：从 Git 部署、Forever/Upstart 保活、集群 API 多核、静态文件 Nginx/CDN（L8657–L9050）。
- 第 13 章 超越 Web 服务器：Socket.IO 实时通信、TCP/IP 与 Buffer 字节序、process 环境变量、child_process 子进程与超时、命令行工具（L9050–L9659）。
- 第 14 章 Node 生态系统：GitHub 协作、npm 贡献与包规范（L9660–L10000）。
- 附录 A/B/C：安装、调试（DEBUG 环境变量、console.log）、Express 扩展与配置。

重点复核段落：第 3 章「异步开发的难题」与「串行/并行流程控制」（L2100–L2400）；第 4 章「先发制人的错误处理」（L2893）；第 5 章「基于文件存储的并发问题」（L3180–L3260）；第 6 章「为什么中间件的顺序很重要」与「错误处理中间件」（L4060–L4520）；第 7 章「limit() 请求主体的限制」与「csrf() 跨站请求伪造防护」（L5140–L5300）；第 10 章「异步单元测试可以并行运行，必须确保测试不会相互干扰」（L7220–L7260）。
