## 三、真缺口

**零缺口。** 本书可推广的工程原则（标准化可重用代码、命名空间与打包、分离式 DOM 脚本、测试套件、表单快速失败、Ajax 异步纪律）已由 T2/T3/T4/T5/T7/T8/T10/T11、C2/C11/C26/C28/C29/C30、F5 承载；其余为 2008 年前后的 JavaScript 语言与前端教程，不落真源。

## 四、重点候选裁定（防后人重复发现）

1. **命名空间 / 打包 / 压缩不另立。** 现代模块系统（ES module）已替代命名空间对象；其“边界与命名冲突”由 T3/T4/T5 承载，压缩是构建工具而非规范。
2. **类式/原型式继承（Base/Prototype 库）不另立。** 属历史兼容层实现；现代 JavaScript 的 class/prototype 语义是语言事实，不抄进产品仓。
3. **分离式 DOM 脚本（Unobtrusive JavaScript）不另立为独立条目。** 其本质是“内容/表现/行为分离”，已由 T4 与 C11 承载。
4. **单元测试框架（JSUnit/J3Unit/Test Simple）不另立。** 测试维度由 C26/C28/C29/C30 与 verify 阶段页承载；具体框架是工具选择。
5. **表单验证规则集合不另立。** “非法输入立刻拒绝”由 T8/C2 承载；具体正则与规则集合是前端实现细节。
6. **Ajax / JSON / RSS / 自动补全 / wiki 案例不另立。** 属前端教程；异步纪律由 T10/T11 承载，具体 API 是工具教程。
