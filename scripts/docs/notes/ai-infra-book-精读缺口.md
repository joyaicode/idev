## 二、缺口汇总（IF1–IF24，按落点归组）

### conventions/canon.md — T9（优化与度量）

**IF1 优化先对上界，差距二分归因**（ch01 L365/L450；T9 DO 扩句）
优化前先按资源与工作量推出可达上 / 下界，实测与界之差按二分归因——估算漏项（补项修正估算）或实现开销（定位后消除）；「比旧实现快 X%」没有上界对照不算结论。

**IF2 收益按占比折算**（ch07 L858–864/L1023；T9 DO 并入）
性能优化先量出目标项在总耗时 / 总流量中的占比，收益按占比折算（局部加速 s 倍，整体只有 (T_c+T_n)/(T_c+T_n/s)）；占比被他项盖住时，改优化关键路径上那一项。

**IF3 瓶颈迁移判据**（ch08 L458–L588；T9 DO 并入）
优化一项资源前，先算改动后哪一项会成为新瓶颈，并写出使原优化仍然划算的边界条件；越线时收益反转的量要给出交点公式或实测交点。

**IF4 口径差与实现差分开**（ch04 L1056–1087；T9「测量方法须可信」句并入）
性能与预测有差距时，先分「口径差」（模型漏了缓存命中、固定开销等未计项）与「实现差」（可去掉的额外工作）两类，先修正口径再计开销，两类不得混算成一笔。

**IF5 差三个数量级先疑模型假设**（ch12 L365–375；T9 DO 或假设台账挂靠）
实测与模型预期差三个数量级以上时，先怀疑模型前提（哪条假设在这条路径上不成立），不先改实现——机制假设未验证前，按规则执行的实现不算错。

### conventions/canon.md — T10（状态与并发）

**IF6 存储类方案三笔账**（ch02 L236–286/L907；T10 DO 扩句）
涉及数据驻留 / 缓存 / 状态保持的方案须算三笔账并各给数字或 UNPROVEN：常驻量、累计访问量、峰值占用量；三笔可相差数量级，只报其中一笔不算算清。

**IF7 异步交付三完成事件**（ch07 L526–538 + ch08 L298–302；T10 并发/异步条款并入）
异步 / 跨边界交付区分三个完成事件——送达、对接收方可见、消费完毕；「传输完成」「调用返回」不得冒充「可复用」；等待边缺边=正确性缺陷，无关边=性能缺陷。

**IF8 汇合成本由最晚就绪者决定**（ch06 L483/L313–322/L415；T10 并发段并入）
多方汇合的等待成本由最晚就绪者决定：评价加速交换 / 汇合的收益前，先写明各参与方的就绪时刻分布；就绪时刻相差越大，加快交换本身的收益越小。

**IF9 缓存/复用键完整性**（ch09 L497；T10「派生与副本」并入）
缓存与复用的键必须由生成该结果的全部输入维度（版本、位置、格式）决定；「内容相同」不等于可复用——键漏一维不会报错，只会静默复用错数据。

**IF10 恢复等待上限＝重做成本**（ch09 L605/L551–559；T10 恢复目标句挂靠）
恢复路径上的等待以重做成本为上限：等待取回 / 恢复一旦超过重做所需时间，即切换到重做路径，禁止无条件等待。

**IF11 容量扩容≠处理速率**（ch07 L644–656；T10 队列/水位条款并入）
扩缓冲 / 槽位只吸收突发，持续吞吐上限由下游完成处理速率决定；把扩容当提速的方案，须同时写明突发容量与持续速率两个数。

### conventions/canon.md — T11（可观测）

**IF12 SLO 按百分位声明**（ch03 L57/L123–128；T11 SLI/SLO 句并入）
SLO 目标值按百分位（如 p95）声明，不只用均值；均值掩盖较慢的请求。

**IF13 一次准备的回本轮数（引入侧）**（ch11 L221/L259–287；T11「持久连接」句扩展）
引入一次性准备（预热、预建、初始化、迁移、快照）时，写明后续每次节省多少、至少使用多少次才覆盖准备成本；预计使用次数不足回本轮数的不做。

**IF14 一次准备的释放侧**（ch12 L325/L642；与 IF13 合并为一条）
复用一次性资源时同时写明保持成本：两次使用间隔超过回本周期后主动释放并重建；保留和重建哪边划算，由等待长度与准备成本比较决定。

### conventions/canon.md — T12 / T13 / A4 / A6 / A7 / F2

**IF15 取舍三角显式化**（ch08 L173–187/L434–448；T12 DO 并入）
方案记录除被拒方案外，显式写明牺牲了哪一角（吞吐 / 单请求延迟 / 资源成本）；同一资源的两种用法与不同资源之间的换算，都要能说出换掉了什么、换回了什么。

**IF16 统计口径是契约**（ch10 L313–321/L727–733；T13 DO 句尾挂靠）
对外报告的统计数字必须写明口径：分子分母各取什么、按什么单位平均——口径变即语义变，沿用旧名而改口径＝改了契约。

**IF17 恢复状态清单按「丢什么会改变行为」枚举**（ch10 L511–527/L501–507；A4 并入）
逐项问「丢了这一项，恢复后的执行会与不中断时不一致吗」——会者必入快照；清单外的隐式状态（缓冲残余、随机状态、进度位置）是最常见的漏项。

**IF18 状态放置与载体生命周期匹配**（ch11 L414–424；T10 DO 或 A4 补句）
跨中断 / 跨阶段必保的状态，放在生命周期不短于所需保存时长的载体上；会被抢占 / 回收的载体上只放丢了可重算的中间结果。

**IF19 容量分窗核算**（ch03 L75–139/L701；A6「容量与失败域」并入）
容量与瓶颈估算按负载到达的时段组成分窗核算，突发积压与排空时间单列；不得以全局均值代替峰值——平均量够用不等于各时段够用。

**IF20 排空期限检查**（ch09 L678–684/L775–778；A6 故障余量句挂靠）
恢复 / 扩容方案要过排空检查：恢复时长按「积压清零时刻」计而非「服务就绪时刻」；净消化≤0 的方案排空时间为无穷，不可行。

**IF21 数据搬移五问进 arch**（前言 L61、ch01 L361；A6 扩句或 deliver SKILL.md arch 自查补一行）
方案涉及数据流动或带性能主张时，design.md 须按五问给数量级估算：每段搬什么、单次多少量、累计几次、经过哪条路径、哪些步骤必须串行等它；算不出的段标 UNPROVEN，禁止只写「应该更快」。

**IF22 沿用既有做法须核对成立前提**（ch01 L440/L452；A7 扩句）
A7 沿用的每个现有做法写明其成立前提（当时的负载量级 / 环境条件），本票条件下前提已变的不直接沿用。

**IF23 固定形状基准不代实际负载**（ch06 L556/L558；F2「观察到」并入半句）
自证式测试另含：用固定形状 / 等长数据的基准测试冒充实际负载（实际是变长、不均匀的），测得的速度对真实工况不成立。

### conventions/coding-tables.md — C19 / C23

**IF24a 异步交接「写完≠用完」**（ch05 L81–92；C19 纠正列并入半句）
异步交接的缓冲 / 连接：「写完」与「用完」是两个时刻，每次交接须显式标出最后使用者，且完成信号覆盖所有路径（含异常、提前返回、取消）；漏一处即死等。

**IF24b 跨端数值带来源标记**（ch10 L705/L743–757；C23 挂靠）
同一数值在任意两端分别计算时，必须记录其来源与版本（谁算的、何时、哪份权重），使用处显式对账；直接以一端重算值静默顶替另一端记录值，视作 F2 幻觉依赖。

### deliver/references/req-quality.md / experts.md / deliver SKILL.md

**IF25 性能类验收总量与个体双指标**（ch01 L301–305/L454；req-quality §1 补例）
性能类目标须同时给总量指标（吞吐 / 完成量）与个体指标（单请求 P95 延迟），只给其一视为待拷问项。

**IF26 成功任务成本口径**（ch03 L71/L175–187；req-quality §5 新增一条）
方案 / 工具 / 模型比较按「成功任务成本」：分子含全部失败尝试与工具、环境成本，分母只计通过验收的任务；零成功的批次只记消耗与失败原因。

**IF27 失败路径支出计入单位成本**（ch11 L625–634/L484；req-quality §5 并入）
估算含重试 / 恢复 / 降级流程的方案时，单位成本按全部尝试支出 ÷ 成功数计算，按路径概率加权。

**IF28 估算附已计入/未计入清单**（前言 L19/L21；req-quality §5 补强）
数量级估算随附两行清单：已计入项、已知未计入项；未计入项中足以改变结论的列为待补测，不静默忽略。

**IF29 两类正确性分列**（ch03 L185/L220；req-quality §3 并入）
接口 / 格式正确性与内容 / 业务正确性分列为独立验收标准；两类错误该改的地方不同。

**IF30 对照条件声明**（ch02 L883–885/L909；req-quality §1 补例）
对比类指标（快 X%、省 Y%）写明对照条件：同输入规模、同环境、同测量口径；口径不同的对比是待拷问项，不得直接作目标值。

**IF31 按时完成按分布判定**（ch12 L602–608/L488；req-quality §1 或 A6 挂靠）
含完成期限的指标不能只验平均值：慢轮 / 慢样本主导完成时间，验收写 P(T≤D) 的目标值与测量方法；平均速率达标不等于期限达标。

**IF32 有效吞吐与准入上限**（ch08 L616–636/L691；experts.md test→done 行并入）
分子只计既正确又按期的请求，完成吞吐与有效吞吐的差额要能解释花在了哪；配置比较时找出有效吞吐开始下降的到达率，准入上限设在下降点之前。

**IF33 部署位置三笔账**（ch12 L3/L148/L556–566；deliver SKILL.md arch 步骤或 experts.md arch 行）
方案涉及部署位置 / 形态时，design.md 必须写三个数的比较：节省的计算时间、新增的传输量与等待时间、准备 / 迁移成本与预计使用次数。

**IF34 数据驻留先于性能成本比较**（ch12 L550–552；experts.md arch 行或 A6 补句）
方案比较前先过数据边界约束：数据不能离开的设备 / 地域 / 信任域直接排除相应方案，再比较时间与成本。
