## 四、重点候选裁定（防后人重复发现）

1. **模块依赖环不另立。** 循环依赖的「加载次序不可控」已由 T4（依赖方向图）与 A2（依赖方向图 `A → B`）承载；再加一条会与 T4 重复。
2. **Promise / 异步流控制不另立。** 异步与并发的纪律已由 T10（数据系统是权衡）与 T11（可运维性：超时/重试/观测）承载；Promise 是语言机制，非规范。
3. **生成器 + Promise 的同步化写法不另立。** 属语言特性；「错误向上传播、不吞异常」已由 C38 与 T8 承载。
4. **ES6 新语法（let/const/箭头/解构/模板字面量）不另立。** 语言级别选型由 `conventions/java.md` 类语言尺与具体仓的语言级别决定；不把语法特性当交付默认抄进真源。
5. **元编程（Symbol.species/iterator）不另立。** 高级语言特性，无工程缺口。
