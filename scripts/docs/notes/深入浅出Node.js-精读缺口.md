## 四、重点候选裁定（防后人重复发现）

1. **异步并发控制（限流/超时/拒绝）不另立。** T11（外部调用超时与连接池上限、下游失败熔断）与 T10（无界重试禁止）已承载；bagpipe 的 limit/timeout/refuse 是其在 Node 的具体实现。
2. **慎将内存当做缓存不另立。** T10「无失效策略的缓存」禁止项已承载；LimitableMap/LRU 是缓存上限的具体实现。
3. **关注队列状态不另立。** T10（无界重试禁止）与 T11（队列上限/背压/熔断）已承载；生产者>消费者堆积是背压的典型信号。
4. **异步异常处理（try/catch 对回调无效）不另立。** T8/C7/C38 已承载「异步错误必须显式传递、不得静默吞」；error-first 回调与 Promise rejection 是其在 JS 的具体约定。
5. **回调地狱不另立。** C9/C1/T3 已承载「卫语句、拆职责、深模块」；Promise/流程控制库是其解法，属语言/库层。
6. **基准测试驱动开发不另立。** T9「无基线不优化、度量才可信」已承载；benchmark/ab 是其工具。
7. **可测试性设计（分层/接口分离）不另立。** T6（护栏先行）与 T3（深模块）已承载。
8. **多进程/集群/负载均衡/自动重启/状态共享不另立。** T11（可运维性）与 T10（状态共享/一致性）已承载；Cluster 是其运行时实现。
9. **日志/监控/稳定性/异构共存不另立。** T11（结构化日志、指标、告警、回滚、灰度、降级）、A6（护栏）、T4（依赖边界）+ 绞杀者模式已承载。
10. **事件发布/订阅模式不另立。** T10「消息消费拓扑（点对点/发布-订购）」已承载；EventEmitter 是其 JS 实现。
