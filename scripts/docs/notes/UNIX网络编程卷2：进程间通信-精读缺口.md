## 四、重点候选裁定（防后人重复发现）

1. **「IPC 对象资源成对释放」不另立。** C19 已要求同层成对、释放显式，不单列。
2. **「互斥锁 / 条件变量 / 读写锁 / 信号量 / 记录锁」不另立。** 已由 T10（并发控制 / 锁排序）与 C39（锁按值复制）承载。
3. **「共享内存与同步」不另立。** 已由 C18（显式交换格式）与 T10（一致性）承载。
4. **「消息队列失败语义」不另立。** 是 T10（队列 / 失败语义 / 消费拓扑）的实例。
5. **「IPC 性能比较」不另立。** 是 T9「先度量再优化」的实例。
