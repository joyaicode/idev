## 三、真缺口

**无。** 本书是 TCP/IP 协议权威参考，其可推广的工程原则（分层抽象、端到端可靠性、超时与重试、流量与拥塞控制、状态显式化、数据完整性）已全部被 `T3/T4/T8/T9/T10/T11`、`C23/C31`、`A4` 与 `canon.md` §2/§4 的超时 / 重试 / 幂等信号承载。无新增真缺口。

## 四、重点候选裁定（防后人重复发现）

1. **「分层模型」不另立。** T3/T4 已承载「接口小、内部厚」与依赖边界；TCP/IP 的四层是协议事实，不是通用架构规范。
2. **「超时 / 重传 / 连接池上限」不另立。** `canon.md` §2「新增外部依赖调用，无超时或连接池上限 → T8 T11」与 §4「重试一下 → T10 T8」已承载。
3. **「拥塞控制（慢启动 / 拥塞避免）」不另立。** T9「无基线不优化」与 T10「权衡」已承载性能决策；具体算法是协议事实。
4. **「滑动窗口 / 流量控制」不另立。** 接收方背压已由 T10 权衡与 A4 一致性等级承载。
5. **「三次握手 / 四次挥手」不另立。** 协议时序，不进通用规范。
6. **「RTT 估计 / Nagle 算法」不另立。** 性能优化算法，T9 已要求「要数字」。

## 五、不建议落的内容
