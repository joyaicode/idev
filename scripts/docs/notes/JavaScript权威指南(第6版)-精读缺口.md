## 四、重点候选裁定（防后人重复发现）

1. **严格模式（use strict）不另立。** 属 JavaScript 专有语法；其“未声明变量抛错、不静默兜底”的可执行要求已由 T8/C2 承载，不把单语言语法指令抄进多语言真源。
2. **作为命名空间的函数 / 模块不另立。** 现代 ES module 已替代；其“边界与公开面”由 T3/T4/T5 承载。
3. **隐式全局变量（不写 var）不另立。** 已由 T14 与 §2 信号承载（新增可变共享状态）；具体 var 提升规则是语言机制。
4. **类和原型 / Java 式类继承 / 子类不另立。** “组合优于继承”由 C27 承载；具体原型链与 class 语法是语言机制。
5. **客户端存储选型（localStorage/cookie/IndexedDB/离线应用）不另立。** 数据真相之源与一致性由 A4/T10 承载；具体存储 API 是浏览器机制。
6. **Web 套接字 / Comet / 服务器推送不另立。** 连接池、背压、可运维性由 T10/T11 承载；具体传输协议是选型。
7. **jQuery 类库不另立。** 属工具库；其“不猜第三方 API、先读源码”由 F2 承载，具体 API 是库教程。
