# 《如何阅读一本书》精读缺口报告

> 源文本：`scripts/docs/notes/如何阅读一本书-全文.txt`（Mortimer J. Adler / Charles Van Doren《How to Read a Book》中译，郝明义 / 朱衣译，145 页带文本层，经 macOS PDFKit 逐页提取）。本报告为第 59 本精读，对照 `conventions/canon.md`、`conventions/coding-tables.md` 裁定真缺口。
>
> 边界：编号真源仍只认 `canon.md` 的 T/A/F 与 `coding-tables.md` 的 P/C/R；本书「第 N 章 / 第 N 层次」序号只作溯源，不建第二套编号。阅读方法论本身（检视阅读 / 分析阅读 / 主题阅读的规则）是读书方法，不进产品仓真源；可迁移到工程上的「先读后写 / 不猜 / 批判性读证据」原则落阶段页，不改 T/C/P/R 计数。

## 一、精读范围

全书四篇 21 章 + 附录读完，主区间如下（行号指 `如何阅读一本书-全文.txt`）：

- **第一篇 阅读的层次（第 1–5 章）**：约 L255–L900。主动阅读、阅读的目标（为资讯 vs 为理解）、基础阅读、检视阅读（系统化略读 / 粗浅阅读）、自我要求的读者（四个基本问题、做笔记、养成习惯）。
- **第二篇 分析阅读（第 6–12 章）**：约 L900–L2900。书籍分类、透视一本书（书名/序/目录/索引）、与作者找共通词义、判断作者主旨、公正评断、赞同或反对。
- **第三篇 阅读不同读物的方法（第 13–19 章）**：约 L2900–L4300。实用书、想象文学、历史、科学与数学、哲学、社会科学。
- **第四篇 主题阅读（第 20–21 章）**：约 L4300–L5850。主题阅读五步骤、检视阅读在其中的角色。

重点复核段落：主动阅读 L255–L300；四个基本问题 L760–L900；检视阅读的系统化略读五步 L700–L820；分析阅读三阶段 L1800–L2100。

### 2. 阅读方法论是读书技巧，不落编码表

检视阅读 / 分析阅读 / 主题阅读的具体规则（分类、找词义、找主旨、找论述、评断）是「怎么读一本书」的方法，不是「怎么写代码 / 怎么设计架构」的规范。其可迁移部分（先读后写、不猜、批判性读证据）已被 T2 / F2 / evidence 承载，不另立条目。

## 三、真缺口

**无。** 本书是阅读方法论经典，其可推广到工程上的原则只有一条主线——「动手前先读懂对象、不靠猜、对证据保持批判」——已完整落在 `T2`（先读后写）、`F2`（幻觉依赖：使用没读过源码的 API）、`evidence.md`（证据规则）与 `context-stage.py`（两阶段读）上。检视阅读的「先看目录 / 序 / 索引再深入」与 idev 的「薄目录 → 加载区间」同构。无新增真缺口。

## 四、重点候选裁定（防后人重复发现）

1. **「四个基本问题」不另立为需求拷问条目。** 它已由 `req-quality.md` 的目标 / 非目标 / 边界 / 细节拷问与 `grilling` 承载；再加一层「阅读四问」会与现有需求密封流程重复。
2. **「检视阅读五步」不落成代码阅读规程。** `context-stage.py` 的两阶段读（薄目录 → 加载区间）与 `codegraph` 符号定位已经是工程化的「系统化略读」；把书名页 / 序 / 索引的读书步骤搬进产品仓会脱离代码语境。
3. **「分析阅读三阶段」不落。** 分类 / 找词义 / 找主旨是文本分析技巧，对应到工程上就是「读源码 + 读契约 + 读测试」，已由 F2 / evidence 承载，不单列。
4. **「主题阅读」不落。** 多本书交叉对照在 idev 里就是「精读层把书收敛到真源编号」这一层；它是流程，不是编码规范。
5. **「逗留与倒退 / 阅读速度」不落。** 纯个人阅读技巧，与代码质量无关。

## 五、不建议落的内容

- 检视阅读 / 分析阅读 / 主题阅读的逐条规则表：读书方法，重复书籍目录，违反精读层「只落缺口」边界。
- 四个基本问题、三种做笔记方法、阅读习惯养成：个人学习方法，不进真源。
- 阅读不同读物（实用书 / 想象文学 / 历史 / 科学 / 哲学 / 社会科学）的分类规则：与工程规范无关。
- 主题阅读五步骤与练习实例（进步论）：研究技巧，不进真源。
- 附录（建议阅读书目、四种层次的练习测验）：阅读训练材料，不进真源。
