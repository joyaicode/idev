## 四、重点候选裁定（防后人重复发现）

1. **「接口与实现分离 / 信息隐藏」不另立。** T3（深模块）/ T4（依赖边界）已承载；「public 接口 / private 实现」是 T3 在 C++ 类的具体表现。
2. **「数据抽象」不另立。** T3 已承载；P6 已承载「只有一种实现就写具体类型」。
3. **「组合优先于继承」不另立。** C27 已承载（复用走组合 / 依赖 / 聚集）。
4. **「继承只为行为多态（is-a）」不另立。** C27 已承载（is-a 成立才继承且子类完整实现父类行为）。
5. **「多态可互换对象」不另立。** P5 已承载（按类型选算法，一处 Strategy / switch）。
6. **「资源成对配平（构造 / 析构）」不另立。** C19 已承载（同层成对、显式释放、覆盖所有路径）。
7. **「命名即设计（namespace / 名字控制）」不另立。** T5 已承载。
8. **「类型安全（const / 内联替代宏）」不另立。** C36/C37 已承载边界与误写检查。
9. **「先写测试（极限编程）」不另立。** T6 已承载（护栏先行，先补测试钉住现有行为）。
