## 一、精读范围

全书 12 章 + 附录读完，OCR 主区间如下（行号指 `算法设计与分析（第3版）-OCR.txt`）：

- **第 1–2 章 绪论 / 算法分析基础**：算法与数据结构、数学分析框架、渐进符号、经验分析。
- **第 3–5 章 蛮力法 / 减治法 / 分治法**：选择排序、顺序查找、插入排序、折半查找、归并排序、快速排序。
- **第 6–8 章 变治法 / 时空权衡 / 动态规划**：预排序、散列、B 树、背包问题、最优二叉查找树。
- **第 9–10 章 贪心技术 / 迭代改进**：Prim / Kruskal / Dijkstra、最大流、匹配。
- **第 11–12 章 算法能力的极限 / 超越算法能力的极限**：P/NP、下界、回溯、分支限界、近似算法。

重点复核段落：第 1–2 章复杂度分析框架与渐进符号；第 3–5 章减治 / 分治（循环不变式与递归收敛）；第 11–12 章算法极限。

## 四、重点候选裁定（防后人重复发现）

1. **「复杂度分析（渐进符号）」不另立。** T9 已要求「无基线不优化、要数字」；渐进符号是算法课记号。
2. **「循环不变式」不另立。** C33 已承载「复杂循环说不出每轮保持什么为真」。
3. **「递归收敛」不另立。** C20 已承载「迭代 / 递归收敛依赖隐式状态变化」。
4. **「按类型选算法」不另立。** P5 已承载「按类型选算法，一处 Strategy 或经典 switch」。
5. **「时空权衡（空间换时间）」不另立。** T9 / T10 已承载「先正确再优化、权衡」。
6. **「算法极限（P/NP）」不另立。** 理论课内容，不进工程规范。
