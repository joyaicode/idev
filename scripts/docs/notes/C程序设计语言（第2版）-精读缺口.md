## 四、重点候选裁定（防后人重复发现）

1. **`getchar` 返回 `int` 而非 `char`（哨兵值类型宽度）不另立。** 第 1 章 1.5.1「这里之所以不把 c 声明成 char 类型，是因它必须足够大，除了能存储任何可能的字符外还要能存储文件结束符 EOF」（L459–L462）。这是 C 语言「返回值域与哨兵值域必须可区分」的类型特性；跨语言版（Go `(value, ok)`、Java `Optional`、异常）已由 C21（命令/查询分离）+ P15（禁返回 null 当成功）承载，不单列。
2. **`while ((c = getchar()) != EOF)` 赋值在条件里不另立。** C36（条件里赋值与比较混用）已承载，且书中明言这是「合法且常见」的惯用法（L475「我们经常会看到这种风格」）。
3. **指针算术越界 / 缓冲区溢出不另立。** C37（下标、长度计算无边界检查）已承载。
4. **`strcpy`/`sprintf` 无边界检查不另立。** 同上，C37 已承载。
5. **`malloc`/`free` 不匹配、双重释放不另立。** C19（资源获取释放同层成对）已承载。
6. **`switch` 漏 break 贯穿不另立。** C2（`default` 只承载显式合法缺省）已承载。
7. **宏的陷阱（6.2 宏并不是函数、6.3 宏并不是语句、6.4 宏并不是类型定义）不另立。** C 预处理器特性，不进多语言仓真源。
8. **`static` 限制作用域、`extern` 声明与定义分离不另立。** T3/T4（信息隐藏）、T7（单一知识来源）已承载。
9. **`NULL`/`0` 表示异常不另立。** P15 / F4 已承载。
10. **机器相关代码最小化不另立。** C16/C17 已承载。
