## 四、重点候选裁定（防后人重复发现）

1. **「中断上下文不能睡眠 / 阻塞」不另立。** 是内核专属约束，不是通用代码原则；其可推广部分（慢响应最坏、无界等待拖垮调用链）已由 T11 承载。
2. **「RCU 读拷贝更新」不另立。** 是内核并发机制，通用并发原则已由 T10 / T14 承载。
3. **「VFS 间接层」不另立。** 是 T3（深模块）与 T4（依赖方向）在文件系统层的实例。
4. **「页缓存与回写」不另立。** 是 T10（派生与副本、一致性）的实例。
5. **「引用计数」不另立。** C19（成对释放）已承载。
