## 三、真缺口

**零缺口。** 本书可推广的工程原则（命名规范、松散耦合与分层、避免全局变量、错误快速失败、无基线不优化、部署与构建、资源成对释放、异步与连接池、客户端存储一致性、JSON 与密钥安全、组合优于继承、循环闭包捕获）已由 T3/T4/T5/T8/T9/T10/T11/T14、A4、C7/C11/C12/C19/C24/C27/C31/C34、P1–P19 承载；其余为 JavaScript 语言与浏览器机制教程，不落真源。

## 四、重点候选裁定（防后人重复发现）

1. **命名规范（变量名名词/函数名动词/匈牙利标记法/类型注释）不另立。** 其“语义命名、按职责取名”的可执行要求已由 T5/C12 承载；具体标记法（匈牙利/类型注释）是团队偏好，不固化成通用规则。
2. **松散耦合（解耦 HTML/JS、CSS/JS、应用逻辑/事件处理程序）不另立。** 其本质是“分层与依赖方向”，已由 T4/C24/C11 承载。
3. **变量类型透明（初始化/匈牙利/类型注释）不另立。** 属 JavaScript 弱类型语言的补救技巧；其“领域概念不裸 string/number 传播”由 C25 承载，具体标记法是偏好。
4. **性能优化清单（避免全局查找、优化循环、最小化 DOM 操作）不另立。** 由 T9（无基线不优化）承载，不预设具体优化手段。
5. **部署与构建（压缩/合并/构建过程）不另立。** 由 T11 与 §2 信号承载；具体构建工具是选型。
6. **防篡改对象（Object.freeze/seal/preventExtensions）不另立。** 属 ES5 语言机制；其“不可变默认”由 T14 承载。
7. **客户端存储选型（Cookie/Web Storage/IndexedDB）不另立。** 数据真相之源与一致性由 A4/T10 承载；具体存储 API 是浏览器机制。
