## 四、重点候选裁定（防后人重复发现）

1. **容器无状态化不另立。** T14（可变性默认纯值）+ T10（真相之源）已覆盖「状态写到数据卷、容器本身可随时销毁重建」这一主张；再立「一切容器必须无状态」会与有状态服务（数据库容器）冲突，误报大于收益。
2. **镜像分层与缓存复用不另立。** 属 T7 的「单一事实 + 复用」在构建层的具体表现，不单列。
3. **多阶段构建不另立。** 是 T1「砍偶然复杂度」与 C6「未引用符号删」在镜像构建上的应用，不是新原则。
4. **服务发现 / 滚动更新 / 健康检查不另立。** 已由 T10 / T11 / A6 承载，是「可运维性是架构特性」在容器编排场景的具体化。
5. **镜像签名与最小权限不另立。** C31 已管密钥隔离与「只认平台内建加密实现」，镜像签名是其在分发链路上的实例。
