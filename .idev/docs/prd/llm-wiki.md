# llm-wiki

机读尺：`.idev/task/llm-wiki/baseline.yaml`。问句只在同票 `grill.md`。下面与基线同一批 id，密封前一起改。

## 目标

交付票往下走时，用不可变来源、索引和内核 schema 这三层，把基线、方案、代码、用例和经验对到同一说法。校准是对照来源标出一致或漂移。两处说法冲突就停。

## 非目标

不安装 nvk/llm-wiki、llmwikify 或其他 wiki 引擎。不建向量库。不做健康分。不把 idev 技能正文再编译成一份 wiki。不收录个人或团队研究笔记。不改产品控制台的 Agent 知识库。不把耗时下降写成验收。不把校准加进 check-feature 作为新的阶段门禁。不把 lessons 或 realign 的结果抄进索引，也不替换这两套。

## 条目

| id | 要求 |
|----|------|
| B1 | 内核提供 schema 和操作，规定摄取、查询、校准怎么做。 |
| B2 | 不安装第三方 wiki 引擎，不建向量库，不做健康分，不编译第二份内核文档，不收录个人笔记，不改产品控制台知识库，不把耗时写成通过条件，不把校准加进 check-feature。 |
| B3 | 索引中每条记录都有非空来源路径。来源中不存在的句子不能写入记录。查询输出该来源路径。 |
| B4 | 索引文件只出现在当前票目录。仓根和内核里不新增跨票索引。 |
| B5 | 索引只收录已经写进该票方案、拆解或用例的主张。只出现在聊天里的句子不产生记录。来源路径指向这些工件，或它们点名的基线条目、代码、已晋升经验和规约。 |
| B6 | 一条记录与其来源不一致，或同一事项的两条记录互相矛盾时，校准退出码非 0，并打印所涉来源路径。 |
| B7 | 方案、拆解、用例相对基线的漂移仍由 realign 报告。经验的新增、升级和召回仍只走 lessons。索引不复制这两套的正文，也不作为它们的查询入口。 |
| B8 | 写该票的方案、拆解或用例之前跑校准。退出码非 0 时不写这一份。 |
| B9 | 改索引记录所点名的代码之前跑校准。退出码非 0 时不改这些文件。 |
